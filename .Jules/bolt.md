## 2025-10-10 - Prefer `count_memories()` SQL Aggregates Over `len(list_memories(...))`
**Learning:** `list_memories()` (and `query_memories()`) fetches full SQLite rows, parses JSON `metadata_json` per row, computes status and trust weights, constructs Python dicts, and sorts them. Calling `len(list_memories(limit=10000))` to compute total item counts for multiple categories (such as review queue totals) instantiates up to 40,000 dicts per request, taking ~135ms+. Using `count_memories(MemoryQuery.from_raw(...))` delegates counting directly to SQLite `SELECT COUNT(*)`, executing in ~7.8ms (~17x faster) with O(1) memory overhead.
**Action:** Always check if an aggregate helper like `count_memories()` exists before using `len(list_memories(...))` or `len(query_memories(...))` for counting UI badges, queue totals, or pagination meta.
